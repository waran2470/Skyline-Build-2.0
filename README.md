# Skyline Build 2.0

Three.js + Vite で作った、ブラウザで遊べる3D建築サンドボックスの最初のプロトタイプです。

## 起動

```bash
npm install
npm run dev
```

ブラウザで表示されたURLを開き、「クリックして開始」を押してください。

## 操作

- **WASD** — 移動
- **Space** — ジャンプ
- **左クリック** — 選択中のブロックを設置
- **右クリック** — ブロックを削除
- **1 / 2 / 3** — 壁・床・ランプを切り替え
- **Esc** — マウスカーソルを解放

## 次の拡張候補

保存・読み込み、建築物のスナップ改善、マルチプレイヤー、NPC、GPTを使った建築アシスタントなどを追加できます。
